# 文生图基础提示词模板

本页收集面向初学者的中文文生图提示词模板。所有示例均为通用描述，可在主流文生图平台使用，不绑定任何具体工具或模型。

---

## 四段式提示词骨架

一个稳定、可控的提示词通常由四段组成：

```
[主体], [环境/场景], [风格/光影], [画幅/质量/镜头], 高细节
```

填写顺序建议：先写主体，再补场景，再加风格，最后补质量词。这样更容易判断哪段导致结果跑偏。

---

## 主体描述词库

主体是画面里最该被注意到的元素。描述越具体，模型越不容易自由发挥。

**人物类：**

- 一位穿白衬衫的年轻女性
- 一位戴圆框眼镜的老人
- 一个穿蓝色背带裤的小男孩
- 一位正在喝咖啡的职场女性
- 一群在户外野餐的朋友

**动物类：**

- 一只趴在窗台上的橘猫
- 一只在雪地里奔跑的金毛犬
- 一只停在花瓣上的蝴蝶
- 一群飞过城市天际线的鸽子

**物品/产品类：**

- 一瓶放在大理石台面上的香水
- 一杯冒着热气的拿铁咖啡
- 一台放在木质书桌上的复古相机
- 一束放在透明玻璃瓶里的向日葵

**建筑/场景类：**

- 一座被晨雾笼罩的山间小屋
- 一条雨后反射霓虹灯的街道
- 一间阳光充足的北欧风格客厅
- 一片金黄色的秋日麦田

---

## 环境/场景词库

环境决定画面的氛围和叙事感。

**室内场景：**

- 温馨的家庭厨房
- 极简主义的书房
- 充满植物的阳台
- 暖色调的咖啡馆角落
- 工业风的开放式办公室

**室外场景：**

- 清晨的森林小径
- 黄昏时分的海边沙滩
- 繁华都市的十字路口
- 雪山脚下的湖泊
- 樱花盛开的公园

**天气与时段：**

- 清晨柔和的自然光
- 正午明亮的阳光
- 黄昏温暖的金色光线
- 阴天均匀的散射光
- 雨夜湿润的街道反光

---

## 风格词库

风格词给画面定调。一次只用一个主风格，避免堆砌。

**写实类：**

- 写实摄影风格
- 电影感画面
- 纪实摄影风格
- 微距摄影风格

**绘画类：**

- 水彩插画风格
- 油画质感
- 铅笔素描风格
- 扁平插画风格
- 赛博朋克插画

**设计感：**

- 极简主义设计
- 复古海报风格
- 日系清新风格
- 北欧简约风格
- 波普艺术风格

---

## 光线与镜头词库

光线和镜头决定画面的专业感。

**光线：**

- 柔光侧窗光
- 逆光轮廓光
- 顶光戏剧光
- 霓虹灯反射光
- 自然散射光

**镜头/构图：**

- 中景构图
- 特写镜头
- 广角镜头
- 俯视角度
- 低角度仰拍
- 三分法构图
- 居中对称构图

---

## 质量词库

质量词放在最后，用于提升整体完成度。

- 高细节
- 高分辨率
- 干净构图
- 专业摄影
- 商业广告质感
- 电影级调色
- 锐利焦点
- 自然肤色
- 无畸变

## 可直接修改的完整示例

### 示例 1：人物氛围图

```
一位穿米色风衣的年轻女性，站在秋日落叶铺满的街道上，
写实摄影风格，黄昏侧逆光，中景构图，
高细节，自然肤色，电影感调色
```

### 示例 2：产品展示图

```
一瓶透明玻璃香水瓶，放在大理石台面上，
背景是柔和的渐变米色，极简主义设计，
柔光摄影灯，居中对称构图，
高细节，商业广告质感，干净背景
```

### 示例 3：美食图

```
一碗冒着热气的拉面，放在木质餐桌上，
旁边有一双筷子和小碟配菜，日式餐馆环境，
暖色调自然光，俯视角度，
高细节，食欲感，干净构图
```

### 示例 4：建筑风景图

```
一座被晨雾笼罩的山间小屋，周围是金黄色的秋林，
写实摄影风格，清晨柔和光线，广角镜头，
高细节，宁静氛围，电影感调色
```

### 示例 5：儿童插画

```
一个穿蓝色背带裤的小男孩，在春天的花园里追蝴蝶，
水彩插画风格，明亮自然光，中景构图，

```

### 示例 6：科技海报

```
一台未来感笔记本电脑，悬浮在深色渐变背景中，
赛博朋克插画风格，蓝色霓虹光效，居中对称构图，
高细节，商业广告质感，干净背景
```

### 示例 7：宠物特写

```
一只趴在窗台上的橘猫，窗外是雨天街道，
写实摄影风格，柔光侧窗光，特写镜头，

```

### 示例 8：运动场景

```
运动摄影风格，低角度仰拍，动态构图，
高细节，活力感，自然光
```

## 负面提示词通用版

负面提示词告诉模型「不要出现什么」，常用于排除低质量元素。

```
变形肢体, 多余手指, 低分辨率, 模糊, 扭曲面容,
水印, 杂乱背景, 过度曝光, 噪点, 文字乱码,
畸形五官, 不协调比例
```

针对人物可加强：

```
畸形手指, 多指, 少指, 扭曲四肢, 不自然表情,
不对称五官, 过度磨皮
```

针对产品可加强：

```
杂乱背景, 反光过强, 色偏, 模糊logo, 阴影杂乱,
不自然反射
```

## 画幅比例变体

不同用途需要不同比例。在提示词末尾追加即可。

- 竖屏封面：追加 `竖屏 9:16, 顶部留白用于标题`
- 横屏封面：追加 `横屏 16:9, 适合视频封面`
- 方形图：追加 `正方形 1:1, 适合头像或商品主图`
- 海报：追加 `竖版海报比例, 上下留白`

---

## 练习建议

1. 从「示例 1」开始，只改主体和场景，观察画面变化。
2. 固定主体，只换风格词，体会风格词的影响力。
3. 固定所有词，只改画幅比例，观察构图变化。
4. 给同一张图加不同的负面提示词，对比瑕疵数量。

> 提示词不是越复杂越好，而是越准确越好。先掌握四段式骨架，再逐渐叠加细节。
