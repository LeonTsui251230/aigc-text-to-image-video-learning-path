# 文生图进阶提示词模板

本页面向已经掌握基础提示词结构、希望进一步控制风格一致性与画面质量的创作者。所有示例均为通用描述，不绑定任何具体工具或模型。

---

## 进阶提示词结构：六段式

在基础四段式之上，进阶提示词可以增加「构图控制」和「情绪/叙事」两段：

```
[主体], [环境], [风格], [光影/镜头], [构图控制], [情绪/叙事], [质量词]
```

不是每次都要写满六段，而是根据目标选择控制点。控制点越多，可控性越强，但也越容易因冲突而崩。

---

## 主体细化：从一句话到一段描述

**基础版：**

```
一位年轻女性站在咖啡馆里
```

**进阶版：**

```
一位约 25 岁、黑色中长发、穿米白色针织衫的年轻女性，
侧身靠在木质吧台上，手里捧着一杯拿铁，眼神看向窗外
```

进阶描述的要点：

- 年龄、发型、服装材质与颜色
- 动作与姿态（侧身、靠墙、手捧、眼神方向）
- 表情与情绪（沉思、微笑、专注）
- 与环境的互动（靠窗、坐在沙发上、站在街头）

---

## 风格混合与权重控制

单一风格容易稳定，混合风格可以创造独特画面，但需要主次分明。

**推荐写法：**

```
主体：一杯咖啡，场景：复古咖啡馆角落，
风格：70% 写实摄影 + 30% 胶片颗粒质感，
光线：暖色侧窗光，镜头：35mm 视角
```

**常见风格组合：**

| 主风格 | 辅助风格 | 效果 |
|--------|----------|------|
| 写实摄影 | 电影调色 | 高级感人像 |
| 水彩插画 | 铅笔线稿 | 手绘故事感 |
| 扁平插画 | 复古海报 | 现代商业海报 |
| 赛博朋克 | 故障艺术 | 科技感视觉 |
| 极简主义 | 建筑摄影 | 空间感设计图 |

## 构图控制词库

构图决定视觉焦点和信息层级。

**经典构图：**

- 三分法构图（主体位于画面三分之一处）
- 居中对称构图（适合产品、建筑）
- 引导线构图（道路、栏杆、走廊指向主体）
- 框架构图（门窗、树枝框住主体）
- 留白构图（主体占画面较小比例，大量空白）
- 特写构图（主体占据画面 70% 以上）

**视角控制：**

- 鸟瞰视角
- 平视视角
- 低角度仰拍（显高大、有气势）
- 高角度俯拍（显渺小、显全貌）
- 第一人称视角
- 过肩镜头

---

## 光影氛围词库

光影是提升画面质感的关键。

**自然光：**

- 黄金时刻光线（日出日落前后）
- 蓝色时刻光线（日落后 20-40 分钟）
- 阴天漫射光
- 林间斑驳光
- 窗边柔和光

**人造光：**

- 霓虹灯反射
- 钨丝灯暖光
- 舞台聚光灯
- 柔光箱均匀光
- 烛光/火光

**情绪光：**

- 高对比明暗（戏剧感）
- 低饱和冷光（孤独感）
- 暖色柔光（温馨感）
- 强逆光剪影（神秘感）

---

## 材质与质感词库

质感词让画面更真实可触。

- 金属拉丝质感
- 磨砂玻璃质感
- 亚麻布料纹理
- 大理石冷硬质感
- 做旧皮革纹理
- 半透明果冻质感
- 水珠凝结表面
- 粗糙水泥墙面
- 细腻皮肤纹理
- 釉面陶瓷光泽

---

## 一致性控制：角色卡模板

如果要在多张图中保持同一角色，建议建立角色卡：

```
角色名：小棠
年龄：25 岁左右
发型：黑色中长发，微卷
五官：圆框眼镜，淡妆，温和表情
服装：米白色针织衫 + 浅蓝色牛仔裤
标志性道具：棕色皮质单肩包
常用姿势：侧身站立，手自然下垂或捧着咖啡
```

在每次生成时，把角色卡完整粘贴到提示词主体段，并固定：

- 相同的风格词
- 相同的种子值（如平台支持）
- 一张参考图（图生图模式）

## 进阶完整示例

### 示例 1：品牌调性产品图

```
一瓶透明磨砂玻璃护肤品，放在浅灰色水泥台面上，
背景是极简米白色墙面，点缀一枝干枯芦苇，
北欧极简设计，柔和自然侧光，
居中对称构图，大面积留白，
高细节，哑光质感，高级护肤广告氛围，
16:9 横屏，适合电商详情页首图
```

### 示例 2：电影感人像

```
一位穿黑色大衣的年轻女性，独自站在雨夜霓虹街头，
背景是模糊的城市车流光轨，
电影感摄影风格，高对比冷暖光，
低角度仰拍，三分法构图，
孤独而坚定的情绪，
高细节，自然肤色，电影级调色，
2.35:1 电影画幅
```

### 示例 3：绘本风格场景

```
一只戴着围巾的小狐狸，坐在积雪覆盖的山坡上，
仰望满天星星，远处是温暖灯光的小木屋，
水彩插画混合铅笔线稿风格，
柔和夜光与暖窗光对比，
居中构图，童话叙事感，
柔和色彩，高细节，治愈氛围，
16:9 横屏
```

### 示例 4：科技感概念图

```
一座悬浮在云端的未来城市，建筑群由玻璃与金属构成，
飞行器在楼宇间穿梭，
赛博朋克混合极简建筑风格，
蓝色与橙色霓虹光效，黄昏天光，
广角鸟瞰视角，宏大构图，
未来感与秩序感并存，
高细节，电影级调色，
21:9 超宽画幅
```

## 进阶负面提示词

```
低质量, 模糊, 畸形肢体, 多余手指, 扭曲面容,
水印, 文字乱码, 不协调比例, 过度饱和,
噪点, 色彩断层, 不自然反射, 虚假细节,
重复图案, 构图倾斜, 主体不完整
```

针对写实人像：

```
过度磨皮, 塑料感皮肤, 死鱼眼, 不对称五官,
不自然笑容, 空洞眼神, 头发粘连, 手指粘连
```

## 排障：提示词冲突自查

如果结果总是不稳定，检查以下常见冲突：

| 冲突类型 | 示例 | 解决方法 |
|----------|------|----------|
| 风格词互相矛盾 | 「写实摄影」+「卡通渲染」 | 只保留一个主风格 |
| 光线互相矛盾 | 「强烈逆光」+「正面柔光」 | 明确主光源方向 |
| 画幅与构图冲突 | 「竖屏 9:16」+「广角风景」 | 选择适合比例的内容 |
| 主体过多 | 一句话描述 5 个人 + 3 个动物 | 拆成多张图 |
| 质量词堆砌 | 10 个「高细节」类词 | 保留 2-3 个即可 |

## 练习建议

1. 选一张你喜欢的参考图，反推它的提示词六段结构。
2. 固定主体，只换光影词，生成一套「清晨/正午/黄昏/雨夜」四张组图。
3. 尝试一个风格混合，记录成功与失败的比例。
4. 建立你的第一个角色卡，并测试能否在 5 张不同场景图中保持一致。
