# 视频生成基础提示词模板

本页收集面向初学者的中文视频生成提示词模板。视频提示词比图片提示词更强调「时间维度」：不仅要描述画面，还要描述动作、镜头运动和变化过程。所有示例均为通用描述，不绑定任何具体工具或模型。

---

## 视频提示词五段式骨架

```
[主体], [场景], [动作/运动], [镜头运动], [风格/光线/质量]
```

与图片提示词最大的区别是：必须包含「动作」和「镜头运动」。否则模型不知道画面该怎么动起来。

---

## 动作描述词库

动作是视频的灵魂。描述要具体、可观察。

**人物动作：**

- 缓慢转身看向镜头
- 轻轻撩起头发
- 端起咖啡杯抿了一口
- 从座位上站起来
- 沿着街道向前走
- 挥手打招呼
- 低头翻看一本书

**物体动作：**

- 咖啡杯缓缓升起热气
- 窗帘随风轻轻飘动
- 树叶在风中摇曳
- 水波向四周扩散
- 烟花在夜空中绽放
- 汽车从画面左侧驶入右侧

**自然/环境动作：**

- 云层缓缓移动
- 海浪轻拍沙滩
- 阳光穿过树叶洒下斑驳光影
- 雪花缓缓飘落
- 霓虹灯招牌闪烁

---

## 镜头运动词库

镜头运动决定视频的观感。

**推/拉：**

- 镜头缓慢推近主体
- 镜头缓缓拉远，展现全景
- 快速推进到人物面部

**平移/摇：**

- 镜头向左平移
- 镜头向右缓慢摇动
- 镜头环绕主体旋转

**升降：**

- 镜头缓缓上升
- 镜头从高处下降

**固定：**

- 固定机位，主体在画面中运动
- 轻微手持晃动，增加纪实感

**综合运动：**

- 镜头跟随主体向前移动
- 镜头从远景推近到特写
- 镜头环绕 + 缓慢上升

---

## 时间节奏词库

节奏决定视频的舒缓或紧张。

- 缓慢而平稳地
- 流畅而优雅地
- 快速而有力地
- 轻盈地、梦幻般地
- 舒缓地、冥想般地
- 逐渐地、从容地

---

## 风格与光线词库

视频的风格和光线与图片类似，但要考虑时间连续性。

**风格：**

- 电影感纪实风格
- 梦幻柔光风格
- 科幻霓虹风格
- 自然清新风格
- 复古胶片风格

**光线：**

- 清晨自然光
- 黄昏金色光线
- 室内暖光
- 夜晚霓虹光
- 阴天柔和光

## 可直接修改的完整示例

### 示例 1：人物慢动作

```
一位穿白色连衣裙的年轻女性，站在开满野花的草地上，
她缓缓转身，长发和裙摆随风轻轻飘动，
镜头从侧面缓慢推近到中景，
自然清新风格，午后柔和阳光，
高细节，流畅运动，电影感调色
```

### 示例 2：城市夜景

```
雨夜的城市街道，霓虹灯招牌倒映在湿润的地面上，
一辆汽车从画面远处驶向近处，车灯在地面拉出光轨，
镜头固定在街道一侧，轻微低角度，
赛博朋克风格，冷暖光对比，
高细节，夜晚氛围，电影感
```

### 示例 3：自然风景

```
一片金黄色的麦田，远处有连绵的山丘，
微风吹过，麦浪起伏，
镜头从低空缓慢向前推进，
写实摄影风格，黄昏温暖光线，
高细节，宁静氛围，自然色彩
```

### 示例 4：产品动态展示

```
一瓶透明护肤品，悬浮在浅灰色背景前，
产品缓慢旋转，展示瓶身设计，
镜头固定，产品自转，
极简主义风格，柔和均匀光，
高细节，干净背景，商业广告质感
```

### 示例 5：宠物短视频

```
一只金毛犬在草地上奔跑，嘴里叼着网球，
它跑向镜头，尾巴摇晃，
镜头低角度跟随狗狗移动，
自然光，户外草地场景，
高细节，活力感，温暖色调
```

### 示例 6：美食动态

```
一勺热汤缓缓倒入碗中，蒸汽升起，
镜头俯视固定，近距离拍摄，
暖色调灯光，木质餐桌背景，
高细节，食欲感，柔和光影
```

## 文生视频 vs 图生视频提示词差异

| 类型 | 重点 | 示例开头 |
|------|------|----------|
| 文生视频 | 完整描述画面 + 运动 | 「一片金色麦田，微风吹过……」 |
| 图生视频 | 重点描述运动和镜头 | 「画面中的人物缓缓转身，镜头推近……」 |

图生视频时，画面内容已由首帧图确定，提示词应聚焦于：

- 画面中什么在动
- 动的方式和速度
- 镜头是否运动
- 光影是否变化

---

## 负面提示词：视频版

视频生成除了要排除画面瑕疵，还要注意时间维度的问题。

```
畸形肢体, 扭曲面容, 画面抖动, 突然跳变,
主体消失又出现, 背景闪烁, 不连贯运动,
速度过快, 反向运动, 镜头剧烈晃动,
低分辨率, 模糊, 水印, 文字乱码
```

针对人物：

```
面部变形, 五官漂移, 肢体数量异常,
动作僵硬, 步伐不自然
```

## 时长与运动幅度建议

- 短片段（3-5 秒）：适合做一个小动作或镜头运动，成功率最高。
- 中片段（5-10 秒）：可以讲完一个小动作，但开始出现不稳定风险。
- 长片段（10 秒以上）：建议分段生成再拼接，不要一次出长片。

运动幅度建议：

- 小幅度运动（微风吹拂、眼神移动）最稳定。
- 中幅度运动（走路、转身）需要首帧约束。
- 大幅度运动（奔跑、跳跃）容易出现肢体变形，建议图生视频。

---

## 练习建议

1. 选示例 1，只改「动作」部分，观察同一画面不同动作的稳定度。
2. 固定主体，只换「镜头运动」，体会推/拉/摇的差异。
3. 用同一张首帧图，分别写「小幅度」和「大幅度」两个提示词，对比结果。
4. 把一段长动作拆成 3 个 3 秒片段分别生成，再拼接成完整动作。

> 视频提示词的核心不是「画面多美」，而是「运动多清楚」。先把动作和镜头运动写准，再谈风格。
