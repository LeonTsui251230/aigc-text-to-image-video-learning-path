# 视频生成进阶提示词模板

本页面向希望进一步控制视频一致性、镜头语言与叙事节奏创作者。所有示例均为通用描述，不绑定任何具体工具或模型。

---

## 进阶视频提示词七段式

```
[主体], [场景], [动作], [镜头运动], [时间/节奏], [风格/光线], [质量与一致性控制]
```

进阶阶段，提示词不仅要让画面动起来，还要让运动**可预测、可控制、可拼接**。

---

## 动作拆解：从一句到一段

**基础版：**

```
一位女性在走路
```

**进阶版：**

```
一位穿驼色大衣的年轻女性，从画面左侧走入，
步伐从容，目光平视前方，
走到画面中央时微微侧身，回头看向镜头，
然后继续向前走，从画面右侧走出
```

进阶动作描述的要点：

- 起点与终点（从哪里进、从哪里出）
- 中间节点（走到中央时做什么）
- 速度与节奏（从容、急促、缓慢）
- 眼神与表情（平视、回望、微笑）
- 与环境的互动（踩过落叶、推开玻璃门）

---

## 镜头语言词库

镜头语言是视频的「语法」。

**景别：**

- 极远景：交代环境
- 全景：展示主体全身与环境关系
- 中景：展示主体半身，适合对话
- 近景：展示胸部以上，适合表情
- 特写：展示面部或局部细节
- 极特写：展示眼睛、手指等细节

**运动组合：**

- 推 + 摇：先推进再环绕主体
- 拉 + 升：先拉远再上升，展现宏大场景
- 跟 + 推：跟随主体同时推进
- 固定 + 变焦：机位不动，镜头变焦

**转场暗示词：**

- 画面逐渐淡出
- 镜头缓缓拉远至黑场
- 主体走出画面
- 镜头推近到某个细节，停留

---

## 时间维度控制

视频提示词需要描述「随时间变化」的内容。

**渐进变化：**

- 天空从蓝色渐变为橙红色
- 灯光由暗逐渐变亮
- 人物表情从紧张变为放松

**循环运动：**

- 树叶随风反复摇摆
- 水波不断荡漾
- 烛光轻轻跳动

**一次性事件：**

- 一滴墨水落入清水，缓缓扩散
- 烟花升空，绽放，然后消散
- 门被推开，光线涌入房间

---

## 角色一致性控制

多镜头视频中，角色一致是最难的。建议建立「动态角色卡」：

```
角色名：阿楷
外貌：短发、戴眼镜、穿深色工装外套
动作习惯：走路较慢、喜欢插兜
标志性道具：复古双肩包
固定出场方式：多从画面左侧入镜
```

在图生视频模式下，为每个镜头准备：

- 同一角色不同角度的高质量首帧图
- 固定风格词与光线词
- 固定种子值（如平台支持）
- 一致的镜头运动节奏

---

## 风格一致性技巧

如果要把多个片段剪成一个完整视频，必须保持风格一致。

**锁定元素：**

- 固定主色调（如暖棕、冷蓝）
- 固定光线方向（如统一侧光）
- 固定画面质感（如电影颗粒、柔光）
- 固定画幅比例

**提示词模板：**

```
[具体内容], 电影感纪实风格，
统一暖色调，黄昏自然光，
固定画幅 16:9, 电影级调色，
高细节，自然运动，连贯光影
```

每次生成不同镜头时，只替换 `[具体内容]`，其余保持不变。

## 进阶完整示例

### 示例 1：电影开场镜头

```
远景：一座山间小镇，清晨薄雾笼罩，
镜头从高处缓慢下降并推近，
逐渐聚焦到小镇中央一条石板路上，
一位老人背着竹篓从画面远处走来，
电影感纪实风格，清晨冷蓝色调，
舒缓节奏，高细节，自然光，
2.35:1 电影画幅
```

### 示例 2：角色多镜头一致性

```
镜头 A：中景，阿楷站在公交站台，双手插兜，
看向公交车驶来的方向，表情平静。
镜头 B：近景，公交车停稳，阿楷抬头看向车门，
微微侧身准备上车。
镜头 C：中景，阿楷走上公交车，背影，
车门缓缓关闭。
统一风格：城市纪实，阴天柔光，
冷灰色调，手持轻微晃动，
高细节，自然肤色，连贯动作
```

### 示例 3：产品发布会风格

```
一瓶黑色磨砂护肤品悬浮在深色背景中，
产品缓慢旋转 360 度，
镜头环绕产品做 180 度弧形运动，
同时一道冷白色光线从左侧扫过瓶身，
突出金属质感的瓶盖细节，
科技感极简风格，高对比冷光，
16:9 横屏，商业广告质感
```

### 示例 4：情绪短片

```
一位年轻女性独自坐在窗边，窗外下着雨，
她缓缓转过头，看向窗外，
手指轻轻触碰玻璃上的雨痕，
镜头从她身后缓慢推近到侧脸特写，
情绪：孤独而平静，
电影感摄影，冷色调，雨夜柔光，
高细节，自然肤色，电影级调色
```

### 示例 5：自然景观延时感

```
一片草原，天空中云层快速流动，
光线不断变化，草原上的光影随之移动，
镜头固定在地平线高度，
从白天过渡到黄昏，天空染上橙红色，
延时摄影风格，宏大叙事感，
高细节，自然色彩，电影感
```

## 分段生成与拼接提示词

长视频不要一次生成，而是拆成短片段，每段末尾暗示下一段开头。

**片段 1：**

```
一位女性在森林小径上行走，镜头从身后跟随，
她走到一棵大树前停下，缓缓转身
```

**片段 2：**

```
同一位女性靠在大树上，镜头从正面拍摄，
她抬起头，看向透过树叶的阳光
```

拼接要点：

- 片段 1 结尾的动作 = 片段 2 开头的动作
- 光线、风格、服装保持一致
- 片段 1 末尾可设计「停留」或「黑场」便于剪辑

## 进阶负面提示词

```
画面闪烁, 主体跳变, 背景抖动, 运动不连贯,
镜头剧烈晃动, 人物面部变形, 肢体数量异常,
运动反向, 速度突变, 画面突然裁剪,
低分辨率, 色彩断层, 水印, 文字乱码,
风格不一致, 光线方向突变
```

针对数字人/口播：

```
口型不同步, 面部抽搐, 眼神空洞,
头部不自然转动, 手势僵硬, 身体抖动
```

## 排障：视频不稳定自查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 人物脸部变形 | 运动幅度过大/首帧质量低 | 减小运动幅度，用更高清首帧 |
| 背景闪烁 | 光线描述不稳定 | 固定光线词，关闭随机光照 |
| 主体突然消失 | 运动超出画面 | 控制进出边界，加镜头跟随 |
| 动作和提示词不符 | 描述太抽象 | 用具体动词替换抽象词 |
| 多片段色调不统一 | 风格词不一致 | 建立固定风格模板 |
| 口型不同步 | 口播词与音频节奏不符 | 调整文案节奏，分段生成 |

## 练习建议

1. 把示例 2 的三个镜头分别生成，尝试在剪辑软件里拼接成完整动作。
2. 选一个 10 秒脚本，拆成 3 个 3-4 秒片段，每个片段单独写提示词。
3. 用同一角色卡生成 5 个不同场景镜头，检查一致性。
4. 固定所有风格词，只换「镜头运动」，观察同一画面的不同叙事效果。
